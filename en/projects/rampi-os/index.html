Rampi OS

My workstation environment for the Raspberry Pi 3 B+: Kanban, remote desktop to Windows 11 and a browser in one interface.

Project

Rampi turns a Raspberry Pi 3 B+ into a workstation for a Windows 11 PC. Three modules are at its core: a Kanban board, remote desktop and a browser. Terminals for Codex, Claude Code and Gemini come on top.

What is special

The interface is native Rust with GTK 4 on Wayland and starts as its own labwc session. On first start you create your own account; there is no default password.

Status

Rampi is a pre-release. It is tested with Docker, native ARM64 CI and QEMU images. Tests on real hardware are still outstanding.

Own project

Pre-release 0.6.0-dev.6, hardware test still open
