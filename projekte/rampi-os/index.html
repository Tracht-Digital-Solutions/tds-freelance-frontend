05 / PROJEKTE

Rampi OS

Meine Arbeitsumgebung für den Raspberry Pi 3 B+: Kanban, Remote Desktop zu Windows 11 und Browser in einer Oberfläche.

Projekt

Rampi macht einen Raspberry Pi 3 B+ zum Arbeitsplatz für einen Windows-11-Rechner. Drei Module stehen im Mittelpunkt: Kanban-Board, Remote Desktop und Browser. Dazu kommen Terminals für Codex, Claude Code und Gemini.

Das Besondere

Die Oberfläche ist nativ in Rust mit GTK 4 auf Wayland gebaut und startet als eigene Sitzung mit labwc. Beim ersten Start legt man ein eigenes Konto an, ein Standardpasswort gibt es nicht.

Stand

Rampi ist eine Vorabversion. Geprüft wird mit Docker, nativer ARM64-CI und QEMU-Images. Tests auf echter Hardware stehen noch aus.

Eigenes Projekt
